使用說明

前臺顯示字幕，後臺調整設定。請使用同一台電腦、同一個 Chrome 使用者設定檔，並保持兩個視窗開啟。

開始使用
  1. 開啟字幕前臺，確認原文與翻譯語言。
  2. 在後臺選擇辨識引擎、翻譯模式及語境，按「套用設定至前臺」。
  3. 回前臺按「開始收音」，首次使用時允許麥克風權限；結束時按「停止收音」。
  4. 正式活動前先試講，確認原文、譯文與延遲。

首次下載模型需要網路。Chrome 辨識是否可離線取決於瀏覽器與語言包，請事先斷網測試，勿只看引擎名稱。

新增、切換與儲存語境
  1. 按「新增語境」，輸入容易辨識的名稱。
  2. 在專有名詞欄每行填一個人名、片名或術語；聽錯修正使用「錯字=正字」。
  3. 按「儲存並啟用語境」。切換語境會更新前臺詞彙；收音中可能短暫重新啟動辨識。

切換前請先儲存目前編輯內容。至少保留一個語境；刪除前會再次確認。

匯入文字檔
  1. 若要保留現有語境，先按「新增語境」。
  2. 選擇 2 MB 以內的 .txt 檔；預設 UTF-8，出現讀取錯誤時可改選 Big5。
  3. 檢查原文預覽與候選詞彙。系統只將不超過 40 字的短行列為候選，不會自動理解長篇稿件或擷取所有專有名詞。
  4. 刪除完整句子，補上需要的人名、片名、術語，再按「儲存並啟用語境」。

匯入會更新目前正在編輯的語境。全文只供參考，不會直接當成實際發言或完整辨識提示。PDF、Word 檔請先另存成文字檔。

專有名詞翻譯對照

若已安裝翻譯對照更新，選好原文與譯文語言，每行輸入「原文=固定譯文」，再按「儲存並啟用語境」。例如：小鳳=Xiaofeng（僅示例，請以官方譯名為準）。

同一原文只填一筆；只套用指定方向，反向翻譯需另外設定語境。固定譯法與「聽錯修正」不同：前者控制譯文，後者更正辨識原文。

優先使用完整且有辨識度的名稱，避免用太短的常用字。固定譯法可能影響句子流暢度，請先試譯。

調整字幕外觀與投影

可選主題、字體、字級、對齊；勾選自訂顏色後可改背景與譯文顏色。按「套用設定至前臺」後，到前臺確認。宋體會使用電腦可用的宋體或明體。

在前臺按 F 可切換簡報全螢幕，Esc 離開。投影模式中按鈕可能隱藏，將滑鼠移到左上方或用鍵盤聚焦即可顯示收音控制。使用綠幕時，背景色以綠幕設定為準。

沒反應、沒字幕或設定沒有同步
  • 確認前後臺都從 localhost:8765 開啟，不能用聊天預覽網址或直接雙擊下載的網頁。
  • 確認本機啟動程式仍在執行，兩個視窗使用同一瀏覽器設定檔。
  • 前臺允許麥克風權限；確認語言方向、引擎以及模型是否已準備好。
  • 更新程式後，前後臺都按 Ctrl＋Shift＋R。不要為了重新整理清除網站資料。
  • 沒有聲音卻出現短句，仍可能是辨識幻覺；語境與固定譯法不等於語音偵測，不能保證排除雜音冒字。
設定儲存與活動前檢查

本機編輯會先儲存在此瀏覽器。登入後按「儲存雲端草稿」，再按「發布詞庫」，才會同步給其他使用者。不同瀏覽器、使用者設定檔、連接埠或清除網站資料，可能看不到原設定；原始文字檔與對照表請另外留存。

活動前測試：安靜與雜音、真人短答、片名與人名、長句、翻譯方向、固定譯名、投影可讀性，以及需要時的斷網使用。字幕仍可能出錯，重要內容應由現場人員確認。

User guide

The subtitle screen displays captions; the control panel manages settings. Keep both windows open on the same computer and browser profile.

Getting started
  1. Open the subtitle screen and check the source and target languages.
  2. In the control panel, choose the recognition engine, translation mode and context, then click “套用設定至前臺” (Apply settings).
  3. On the subtitle screen, click “開始收音” (Start listening) and allow microphone access when prompted. Click “停止收音” (Stop listening) when finished.
  4. Test speech recognition, translation and subtitle delay before the event.

Keep both windows open in the same browser profile. Downloading models requires an internet connection. Chrome offline recognition depends on browser and language-pack support; test it offline beforehand.

Contexts and vocabulary
  1. Click “新增語境” (New context) and enter a name.
  2. Enter one proper noun per line. For recognition corrections, use incorrect text=correct text.
  3. Click “儲存並啟用語境” (Save and activate context).

Save edits before switching contexts. Changing vocabulary while listening may briefly restart recognition. At least one context must remain; deletion requires confirmation.

Importing a text file
  1. Create a new context first if you want to keep the current one unchanged.
  2. Choose a .txt file up to 2 MB. Use UTF-8, or select Big5 if decoding fails.
  3. Review the original text and candidate vocabulary. Only nonempty lines of up to 40 characters are suggested; this is not automatic keyword extraction.
  4. Remove full sentences, add the relevant names and terms, then save and activate the context.

Importing edits the currently selected context. The full manuscript is reference material, not a transcript of what speakers have said or a full recognition prompt. Convert PDF or Word documents to plain text first.

Fixed translations for proper nouns

If the glossary update is installed, select a context and the source and target languages. Enter one source term=fixed translation per line, then save and activate the context. Example: 小鳳=Xiaofeng. This spelling is illustrative; use the official spelling.

Use one entry per source term. Entries apply only in the configured language direction; create another context for the reverse direction. Recognition corrections change the recognized source text, while glossary entries control translations.

Prefer distinctive full names over short common words. Fixed translations can affect sentence fluency; test them before use.

Appearance and projection

Choose the theme, font, size and alignment. Enable custom colors to change the background and translated text color, then click Apply settings and check the subtitle screen. Song/Ming fonts use the fonts available on your computer.

Press F on the subtitle screen for presentation fullscreen, or Esc to leave fullscreen. Recording controls may be hidden in presentation mode; move the pointer to the upper-left corner or focus the controls with the keyboard. Green-screen mode takes priority over a custom background color.

Troubleshooting
  • Open both pages through localhost:8765. Do not use a chat preview link or directly open a downloaded HTML file.
  • Keep the local launcher running and use the same browser profile for both windows.
  • Allow microphone access on the subtitle screen. Check the language direction, selected engine and downloaded models.
  • After an update, press Ctrl+Shift+R in both windows. Do not clear site data just to refresh.
  • Words appearing during silence may be recognition hallucinations. Vocabulary and glossary settings do not replace voice activity detection or guarantee removal of noise-triggered text.
Storage and pre-event checks

Edits are stored locally first. Sign in, save cloud drafts, and explicitly publish to share vocabulary. Appearance and microphone controls remain local. A different browser, profile or port—or clearing site data—may make saved settings unavailable. Keep separate copies of your original text files and terminology lists.

Before the event, test silence and noise, short answers, names and film titles, long sentences, translation direction, fixed translations, projection readability and offline operation if needed. Subtitles may still contain errors; important content should be checked by an operator.
